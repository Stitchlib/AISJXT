## 1. 验收标准逐项签收

### ① 安全
| 验收点 | 状态 | 证据 |
|--------|------|------|
| 未授权用户读不到敏感配置 | ✅ | `GET /config` 仅返白名单字段；`secret_key`/明文口令永不外露（H1） |
| 未授权无法控制 WS 指令 | ✅ | `/ws` 须鉴权，未授权关连（4401）；非 admin 启停被拒（4403）（H2） |
| 低权限无法改配置/用户 | ✅ | `PUT /config`、`/users` 仅 admin；viewer 得 403（M5） |
| 默认密钥/口令生产被环境变量强制覆盖 | ✅ | `AIQC_SECRET_KEY` / `AIQC_ADMIN_PASSWORD`；未覆盖启动告警（H5） |
| 跨域收敛 | ✅ | `allow_origins` 默认空（仅同源），由 `AIQC_ALLOWED_ORIGINS` 注入（M8） |
| 视频流令牌不落日志 | ✅ | MJPEG 改用一次性 60s `stream-ticket`（`?ticket=`）（M7） |
| 登录防爆破 | ✅ | 同账号 5 次失败锁 10 分钟（M6） |

安全回归用例：`tests/test_security.py`（H1/H2/M5/H6）、`tests/test_stage4.py`（M6/M8）全绿。

## 3. 容量与压测结论

- **存量容量**：1,000,000 行检测记录下，分页/报表/导出全部达标（见 §1 ③）。
- **并发**：WebSocket 连接数、JWT 鉴权、stream-ticket 取流逻辑均有单测与集成验证；`/system-health` 实时暴露 WS 在线连接数，压测时可观测。
- **内存泄漏**：增量计数器避免了全表扫描与全量加载，写入为 O(1) 累加；`vite build` 与 pytest 长时间运行无异常内存增长迹象。
- **局限（需在真实环境补跑）**：沙箱无法运行 24h 连续检测写入 + 10 WS 客户端并发的真实压测。建议生产部署后用 `tests/performance/test_perf_1m.py` 的相同断言作为巡检脚本，定期跑一遍验收容量门槛。
